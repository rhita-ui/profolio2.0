## ⚙️ Getting Started

Clone the repository:

```bash
git clone https://github.com/rhita-ui/profolio2.0.git
```

Navigate into the project:

```bash
cd profolio2.0
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
